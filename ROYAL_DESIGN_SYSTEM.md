## 3. TYPOGRAPHY HIERARCHY

### Font Family System
```
HEADINGS:
Font: Georgia Serif or "EB Garamond"
Weight: 400 (Regular) for majesty, not boldness
Color: Royal Navy with Gold accents
Letter Spacing: +2px (formal, regal)
Transform: Uppercase for section headers

SUBHEADINGS:
Font: Georgia Serif
Weight: 600
Color: Gold (#d4af37)
Size: Scale down from main heading
Transform: Uppercase with letter spacing

BODY TEXT:
Font: Inter or "Source Sans Pro" (Clean, professional)
Weight: 400
Color: #3d3d3d or #0a1428
Size: 16px (desktop), 14px (mobile)
Line Height: 1.8 (professional documents)

ACCENTS:
Font: All-caps with Georgia Serif
Color: Gold
Size: 12px
Letter Spacing: 2px
Example: "UNDER ROYAL PATRONAGE"
```

### Size Scale
```
h1: 72px (Hero headings)
h2: 48px (Section titles)
h3: 32px (Subsection titles)
h4: 24px (Card titles)
body: 16px (Main content)
small: 14px (Secondary content)
tiny: 12px (Captions, accents)
```

## 8. RESPONSIVE DESIGN RULES

### Desktop (1200px+)
- Full royal header with crest
- Horizontal navigation
- Full-width content sections
- Sidebar elements visible
- All decorative borders shown

### Tablet (768px - 1199px)
- Compact header (logo + menu icon)
- Stacked navigation (hamburger)
- 2-column layouts
- Simplified decorations
- Touch-friendly buttons (48px)

### Mobile (375px - 767px)
- Minimal header (just logo)
- Full-screen hamburger menu
- Single column content
- Large touch targets
- Simplified footer (stack vertically)
- Text remains large and readable
- Heraldic elements simplified

## 10. COLOR USAGE RULES

### Royal Navy (#0a1428)
✅ DO: Headers, section backgrounds, formal text
❌ DON'T: Body text (use lighter), hover states (too dark)

### Gold (#d4af37)
✅ DO: Accents, highlights, borders, key text
❌ DON'T: Large background areas (eye strain)

### Burgundy (#8b1a1a)
✅ DO: Secondary CTAs, emergency content, emphasis
❌ DON'T: Main body text, small text

### Ivory (#f9f7f4)
✅ DO: Page backgrounds, light content backgrounds
❌ DON'T: Text (low contrast on white)
